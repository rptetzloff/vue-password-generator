What this is

A password generator that runs entirely in your browser. It offers seven ways to build a password — Simple, Advanced, Words, Passphrase, Wireless, Mad Lib and Numbers — from single random characters through to memorable word-based passphrases.

Nothing you generate is sent anywhere. There is no account, no server to talk to, and no build step: the site is plain HTML, CSS and ES modules, with its dependencies vendored into the repository. See Legal for the full privacy statement.

Why word-based passwords

A passphrase drawn from a large word list can be far easier to remember than a random string while remaining hard to guess — the strength comes from the size of the pool a word is drawn from, not from how complicated the result looks. The Words mode uses the EFF long wordlist of 7,776 words, the same list designed for physical dice.

Randomness

Every random value comes from the browser's crypto.getRandomValues(), drawn with rejection sampling so that each character or word in a pool is equally likely. Earlier releases used Math.random(), which is not cryptographically secure; that changed in v2.7.2. If you generated passwords before then, they are worth regenerating.
