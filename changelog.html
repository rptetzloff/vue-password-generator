v2.7.2
2026-08-08
Patch
All randomness now drawn from crypto.getRandomValues()
Every generator drew its random values from Math.random(), which is not cryptographically secure — passwords produced before this release should be considered predictable and are worth regenerating.
Security
  • Predictable passwords — all 22 randomness call sites used Math.random(), which V8 implements as xorshift128+. Its internal state can be recovered from a short run of observed outputs, meaning an attacker who saw some generated passwords could predict others. All seven generators (Simple, Advanced, Words, Passphrase, Wireless, Mad Lib, Numbers) were affected.
  • New randInt() helper — draws a uint32 from crypto.getRandomValues() and uses rejection sampling to stay unbiased: draws at or above the largest multiple of the range that fits in a uint32 are discarded, so the remaining values divide evenly. A plain % n would have skewed results toward low values. The randPick, randBool, and randChar helpers wrap it, and every call site now routes through them — including the Fisher-Yates shuffle in Advanced mode.
  • No silent fallback — crypto.getRandomValues() requires a secure context (HTTPS or localhost). Generation now fails loudly rather than falling back to Math.random(), which would quietly reintroduce the same weakness.
v2.7.1
2026-08-08
Patch
Build step removed & runtime assets self-hosted
Removed the Vite build, which the production site never served, and moved Vue and the icon font into the repository. The site now has no dependencies, no build step, and no third-party requests. No change to password generation or the interface.
Security
  • Five advisories resolved by removal — postcss (four advisories, including an XSS via unescaped </style> and path traversal via attacker-controlled sourceMappingURL), plus esbuild, rollup, and nanoid. All were transitive build-time dependencies of Vite and never reached the browser, so no released version of the site was affected. Deleting the toolchain removes them permanently rather than deferring to the next upgrade.
  • No third-party requests — Vue was previously fetched from unpkg.com and the icon font from cdn.jsdelivr.net on every page load, exposing visitors to those CDNs. Both are now served from this site, so no external party observes who uses the generator.
Improved
  • No single point of failure in the CDN — src/main.js imported Vue directly from a CDN URL, so an outage there produced a blank page rather than a degraded one. Vue 3.4.0 and Material Design Icons 7.4.47 are now vendored under vendor/, and the site renders entirely from its own origin.
  • Smaller icon font payload — only the woff2 format is kept; the legacy eot, ttf, and woff variants were dropped, as every browser able to run the app's ES modules supports woff2.
Removed
  • Vite build toolchain — vite, @vitejs/plugin-vue, vite.config.js, and package-lock.json. The project has no npm dependencies at all now. Because index.html loads src/main.js as a native ES module, the browser needs no bundling step, and production has always served the repository directly rather than a build directory.
  • Unused packages — vue and @mdi/font were declared as dependencies but never imported; Vue came from a CDN URL and the icon font from a stylesheet link.
Fixed
  • Blank page from the build output — format: 'umd' in the Rollup options wrapped the app in a UMD factory that read Vue from a global named vue_esmBrowser_prod_js, a name Rollup invented because the Vue import was a CDN URL it could not otherwise name. No such global exists in a browser, so the bundle threw Cannot read properties of undefined before mounting and left the page blank. data/ was also never copied into the output, so the wordlists returned 404 for the word-based modes. The production site was unaffected because it serves this repository directly rather than the build output.

v2.0.0
2025
Major
Full rewrite — six generator modes
Complete rebuild with Vue 3 Composition API, Vite, and six distinct password generation modes replacing the single-mode v1 generator.
Added — New generator modes
  • Advanced mode — per-character-type minimum and maximum count sliders, plus an interactive symbol chip picker with All / Common / None presets.
  • Words mode — dictionary-based passwords from a curated word list; configurable word count (2–20), separator, capitalization, prefix/suffix, and leet-speak.
  • Passphrase mode — slot-based builder with adjective, adverb, noun, and verb slots; each slot has an independent thematic category (Animals, Colors, Mood, etc.).
  • Mad Lib mode — 12 narrative sentence templates; each typed placeholder gets its own category selector; readable phrase preview shown alongside the generated password.
  • Numbers mode — numeric PIN generator with configurable digit count and limits on consecutive repeated and sequential digits.
Added — Shared features
  • Separator picker — 14 built-in options (None, Space, Hyphen, Underscore, Period, Dollar, random symbols/numbers, combinations) plus a free-text Custom option.
  • Prefix & Suffix — independent affix pickers with the same options as the separator, plus two suffix-only mirror modes (Mirror Prefix and Mirror Prefix with new digits).
  • Capitalization modes — Title Case, lowercase, UPPERCASE, random-per-letter, alternating-per-word, and random-per-word.
  • Leet speak substitutions — 10 toggleable character substitutions (a→@, e→3, i→1, o→0, s→$, t→+, l→!, b→8, g→9, z→2) with All / None presets.
  • Word pills — each word in the output appears as a clickable pill that swaps only that word without regenerating the whole password.
  • Affix lock — lock icon freezes the current prefix, separator, and suffix while still allowing individual word re-rolls.
  • Generation history — per-tab history strip showing recent passwords; clicking any entry restores it to the output.
  • History size control — global header chip (Off / 5 / 10 / 20 / 50) configures the history limit across all tabs.
  • Settings persistence — all options saved to localStorage and restored on next visit.
Improved
  • Simple mode retained and refined — character set checkboxes, length slider (6–128), copy button with animated confirmation.
  • Responsive layout — tabs, cards, and affix pickers adapt cleanly from mobile to wide desktop.
  • Privacy notice in the header making the local-only guarantee explicit to users.
Architecture
  • Migrated from Vue 2 (Options API) to Vue 3 Composition API.
  • Build tooling switched from Vue CLI to Vite 5.
  • Vue loaded as an ES module from CDN — no framework bundling.
  • Word data split into wordlist.txt (Words mode) and words.json (Passphrase / Mad Lib) for efficient per-mode loading.
  • Shared composables (useHistory, useCopyPassword, useNotification, persistedRef) eliminate cross-component duplication.
